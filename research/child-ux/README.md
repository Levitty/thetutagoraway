# HOREB — Child-experience research

Testing HOREB from the chair of a **grade-5 student**: doing real maths, getting
things wrong on purpose in realistic ways, and recording exactly what the child
sees and feels at each step. The goal is a concrete, prioritised list of things
to build.

Test account: `horeb.tester@tutagora.com` · placed at **Grade 5 · Numbers**.

## Files
- [`findings.md`](findings.md) — the running log, one entry per scenario, with severity + a concrete fix.
- [`build-backlog.md`](build-backlog.md) — the prioritised list of things to build, distilled from findings.

## Severity key
- 🔴 **Blocker** — a child gets stuck, confused, or learns the wrong thing.
- 🟠 **Hurts learning** — works, but the teaching moment is wasted or demoralising.
- 🟡 **Friction** — rough edge, not fatal.
- 🟢 **Working well** — protect this; don't regress it.
