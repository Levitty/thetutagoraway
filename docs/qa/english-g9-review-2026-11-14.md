- If a child answers "pay nothing": Go back to the text and find the line that answers the question. Check the answer against the text: it must agree with the text, not say the opposite.
- If a child answers "wait longer": Go back to the text and find the line that answers the question. Check the answer against the text: it must be found in the text, not added from outside.

## How to sign a family off

Add its id to the list in `src/ai-tutor/content/families/english_g9_signed.js` (`english_g9_signed`). That is the one switch: a family not in the list is never served to a child.
