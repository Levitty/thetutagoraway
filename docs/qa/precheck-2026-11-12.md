# Pre-review checks (2026-11-12)

Generated by `npm run review:precheck` (`scripts/review-precheck.mjs`, checks in `scripts/lib/item-precheck.mjs`). Free, local and deterministic: no model was called. This is the part of the blind reviewer that needs no model. **The model pass (solve each item without the key) is not built and was not run.**

Sources: 1480 question families (all, signed off or not; 84 of them Grade 5 Science) and 257 generator skills of Maths Grades 1 to 9, 30 draws each: 52110 items.

Checks: **key** (the key marks itself right, exactly one option is right, an arithmetic question computes to its key, a working has one false step); **distractors** (every wrong option carries feedback naming the mistake; Grade 5 families name a library code); **reading** (Flesch-Kincaid at most the grade plus two, no sentence over 30 words, short enough for a phone); **ambiguity** (broken text, two questions in one, vague words, double negatives, an amount with no unit); **units** (metric, shillings, believable ages, speeds, masses, temperatures and prices, British spelling).

Hard means the item must not reach a reviewer. Soft means a reviewer should look.
