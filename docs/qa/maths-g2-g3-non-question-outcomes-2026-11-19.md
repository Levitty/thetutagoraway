# Mathematics Grades 2 and 3: outcomes that are not questions (2026-11-19)

These stay with the teacher. A typed or tapped answer cannot show them, so no question family is written for them.

| Grade | Outcome or part of a skill | What the teacher observes |
|---|---|---|
| 2 | MATH.G2.MEASUR.MASS.d, appreciate measuring mass using fixed units | Attitude: the child uses a balance with care and enjoys weighing class items. |
| 2 | MEASURE_FIXED_MASS, improvising a beam balance (coat hanger, string, tins) | The child builds a balance and weighs with bottle tops of one kind. |
| 2 | MEASURE_IN_KG, measuring with a beam balance and 1 kg masses | The child adds 1 kg masses until the beam is level and records with kg. |
| 2 | MATH.G2.GEOMET.LINES.e, appreciate the use of lines | Attitude. |
| 2 | STRAIGHT_LINES and CURVED_LINES, modelling with sticks, string and clay; drawing with a ruler or freehand | The child models and draws the lines; the questions only ask the child to name and judge lines. |
| 3 | MATH.G3.MEASUR.MASS.e, appreciate measuring mass in kilograms | Attitude. |
| 3 | MEASURE_KG, making 1 kg masses with sand and using a beam balance | The child makes and uses the masses. |
| 3 | ESTIMATE_KG, estimating by holding an object and a 1 kg mass, then checking on a balance | The child holds, estimates, then measures; the questions only ask which estimate is sensible. |
